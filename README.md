# Gravel Bike Electrification Project

This repository contains research and documentation for electrifying the VAN RYSEL GRVL AF DISCOVER gravel bike.

## Contents

- **`electrification-report.md`** - Comprehensive English report analyzing electrification solutions
- **`delivrables.md`** - Project requirements and deliverables specification
- **`solution-proposals.md`** - Technical notes on motor and battery installation approaches
- **`presentation-bike-electrification.pdf`** - Supporting presentation materials

## Report Overview

The main report (`electrification-report.md`) provides:

1. **Introduction** - Requirements, limitations, and technical specifications
2. **Solution Candidates** - Three complete electrification kits with detailed analysis:
   - Candidate 1: Budget Hub Motor Kit (€1,400-1,850)
   - Candidate 2: Mid-Drive Motor Kit (€1,950-2,550)
   - Candidate 3: Lightweight Geared Hub Motor Kit (€1,450-1,950) ⭐ **Recommended**
3. **Comparative Analysis** - Summary table and pros/cons comparison
4. **Recommended Solution** - Final selection with implementation specifications
5. **Market Evaluation** - Comparison with ready-made electric bikes
6. **Conclusion** - Key findings and recommendations

## Key Findings

The **Lightweight Geared Hub Motor Kit (Candidate 3)** is recommended as the optimal solution because it:
- Balances cost, weight, and performance
- Preserves the original 1×8 drivetrain
- Offers modular battery configuration
- Provides easy installation
- Stays well within €3,000 budget
- Achieves 100 km range with <3h charging
- Supports dual R/OR modes (road-legal and off-road)

## Project Requirements

- **Budget:** €3,000 maximum
- **Weight:** <30 kg total (bike ~12 kg + system ~8 kg)
- **Range:** 100 km per charge
- **Charging:** <3 hours
- **Modes:** R (25 km/h road-legal) + OR (off-road unrestricted)
- **Use Cases:** Mixed city and off-road
